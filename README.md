# Kotlin Counter App

This is a simple counter application developed in Kotlin as part of the **Mobile I** course at the **University of Ribeirão Preto (UNAERP)**.

## Description

The application allows users to increment or decrement a numerical counter with a single tap.

It was designed as a simple and practical project to explore basic Android user interface development and event handling with Kotlin.

## Features

* Increment the counter
* Decrement the counter
* Dynamically update the displayed value

## Technologies Used

* **Kotlin** — Main programming language
* **Android Studio** — Integrated Development Environment (IDE)
* **XML** — Used to create the application layout

## What I Learned

Through this project, I practiced fundamental concepts of Android development, including:

* Creating layouts with XML
* Handling button click events
* Understanding the lifecycle of an Android Activity
* Dynamically updating UI elements
* Structuring a basic Android project

## Academic Context

This project was developed for the **Mobile I** course as part of the **Software Engineering** program at the **University of Ribeirão Preto (UNAERP)**.

## How to Run

1. Clone this repository:

```bash
git clone https://github.com/rafaeldonascimento2/App-Contador.git
```

2. Open the project in **Android Studio**.
3. Wait for the project dependencies to synchronize.
4. Connect an Android device or start an emulator.
5. Run the application.
